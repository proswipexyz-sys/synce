Getting Started

導入手順と基本操作メニューです。

注意事項

エミュレーター（Emulator）を使用することを強く推奨します。使用しない場合、バン（BAN）のリスクがあります。

導入手順
  1. まず、以下のリンクからセットアップを済ませてください。
    https://proswipexyz-sys.github.io/install/
  2. 次に、以下のリンクからキーを入力してLoaderをダウンロードします。
    https://loader.cryptauth.net/
  3. ダウンロードしたLoaderを開いてキーを入力します。
  4. カスタムモデルを使用する場合は 1、使用しない場合は 2 を入力します。
  5. 画面に waiting for game と表示されたら、ゲームを起動してください。
操作方法
  • メニューキー： Insert

Troubleshooting

エラーや問題が発生した場合の修正手順です。

クラッシュや接続エラーが発生する場合
  1. VPNの使用：
    1.1.1.1 VPNを導入・使用してください。
    👉 https://one.one.one.one/
  2. 環境の調整：
    上記で治らない場合、Windowsの「時刻の同期」を実行し、PCを再起動してください。
